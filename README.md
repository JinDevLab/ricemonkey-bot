# ricemonkey-bot

메이플스토리 보스 리워드 판매금의 분배금을 계산하고, 누가 경매장에 올렸고 누구에게서 구매했는지 기록하는 Discord 봇이다.
현재는 요청 서명 검증과 PING 응답만 구현한 뼈대다.

## 왜 만들었나

파티원은 경매장에 올린 금액에서 수수료 3%를 떼고 받으므로 판매금을 반으로 나누면 몫이 달라진다.
95,000,000메소를 반으로 나눠 47,500,000메소를 올리면 파티원은 46,075,000메소를 받고 분배자는 47,500,000메소를 가진다.
역산하면 48,223,350메소를 올리면 되고 분배자 46,776,650메소, 파티원 46,776,649메소가 된다.

## 동작 방식

1. 분배자가 총 판매금액, 판매 수수료, 파티원, 비율을 입력한다.
2. 봇이 파티원을 멘션하며 올릴 금액을 안내한다.
3. 파티원이 경매장에 물건을 올리고 등록 버튼을 누른다.
4. 분배자가 물건을 구매하고 구매 완료 버튼을 누른다.
5. 전원 구매가 끝나면 완료 표시를 한다.

분배자 포함 최대 6명, 기본은 정분배이며 비율을 지정할 수 있다.
봇은 게임 거래를 볼 수 없어서 사람이 누른 표시만 기록한다.
미완료 조회로 올릴 건과 구매할 건을 확인하고, 내역 조회로 참여 기록을 확인한다.

## 분배 계산

```text
판매 실수령액 = 총 판매금액 - 총 판매금액의 판매 수수료
파티원 올릴 금액 = 판매 실수령액 × 파티원 퍼센트 ÷ (100 - 0.03 × 분배자 퍼센트)
분배자 최종 금액 = 판매 실수령액 - 파티원별 올릴 금액의 합
```

올릴 금액은 소수점을 버리고 남는 메소는 분배자가 가져간다.
총 판매금액은 100,000,000메소이며 파티원 금액은 1인당이다.

| 판매 수수료 | 분배 퍼센트 | 판매 실수령액 | 파티원 올릴 금액 | 분배자 최종 금액 | 파티원 실수령액 |
|---|---|---:|---:|---:|---:|
| 5% | 2명 정분배 | 95,000,000 | 48,223,350 | 46,776,650 | 46,776,649 |
| 3% | 2명 정분배 | 97,000,000 | 49,238,578 | 47,761,422 | 47,761,420 |
| 5% | 3명 정분배 | 95,000,000 | 31,986,531 | 31,026,938 | 31,026,935 |
| 5% | 6명 정분배 | 95,000,000 | 15,912,897 | 15,435,515 | 15,435,510 |

## 기술 스택

- TypeScript
- Cloudflare Workers + D1
- discord-hono
- Vitest

슬래시 명령과 버튼만 쓰니까 상시 프로세스가 필요 없고 무료 플랜으로 충분하다.

## 개발

프로젝트 루트의 PowerShell에서 실행한다.

```powershell
npm ci
Copy-Item .dev.vars.example .dev.vars
```

`.dev.vars`에 `DISCORD_PUBLIC_KEY`를 넣는다.
**`.dev.vars`는 절대 커밋하지 않는다.**

```powershell
npm run dev
```

```powershell
npm run typecheck
npm test
npx wrangler deploy --dry-run
```

`wrangler.jsonc`의 `database_id`는 자리표시자다. `npx wrangler d1 create ricemonkey-bot` 실행 후 출력된 ID로 교체한다.
**`npm run deploy`는 실제로 배포한다.**
