# 기능 명세
분배 규칙과 용어는 [도메인 문서](domain.md)를 따른다.

## 1. 봇의 역할
봇은 기존 분배 방식의 계산과 멘션, 진행 확인을 대신한다. 게임 안의 거래는 볼 수 없으므로 상태는 사람이 누른 표시만을 기준으로 한다.

## 2. 1차 범위

| 단계 | 하는 사람 | 봇의 동작 |
|---|---|---|
| 분배 만들기 | 분배자 | 총판매액, 판매 수수료, 파티원, 분배 퍼센트(선택)를 입력받아 경매장 등록가를 계산한다. |
| 금액 안내 | 봇 | 파티원을 멘션하고 각자 경매장 등록가와 예상 실수령액을 보여준다. |
| 경매장 등록 | 해당 파티원 본인만 | 버튼으로 입력창을 열어 경매장에 등록한 아이템 이름(필수 한 줄, 최대 100자)을 받고 분배자에게 이름과 금액을 알린다. 구매 전에는 다시 눌러 수정할 수 있다. |
| 구매 완료 표시 | 분배자만 | 경매장 등록을 제출한 파티원만 구매 완료로 바꾸고 해당 파티원에게 아이템 이름과 실수령액을 공개 알림으로 보낸다. 분배자는 알림 대상이 아니다. |
| 분배 완료 | 봇 | 전원이 구매 완료면 메시지를 완료 상태로 바꾸고 이모지를 남긴다. |
| 분배 취소 | 분배자만 | 잘못 입력하면 취소하고 다시 만든다. 이미 구매한 건은 봇이 되돌리지 못한다. |
| 미완료 조회 | 누구나 | 내가 등록해야 하는 건과 내가 구매해야 하는 건을 보여준다. |
| 내역 조회 | 누구나 | 내가 분배자나 파티원으로 참여한 분배를 최근 순으로 보여준다. 날짜, 분배자, 총판매액, 내 몫, 상태를 표시하고 조회한 본인에게만 보인다. |

### 서버 전용 명령
- `/분배`: 필수 `총판매금액`, `수수료`(3%/5%), `파티원1`. 선택 `파티원2`~`파티원5`, `분배자퍼센트`, `파티원1퍼센트`~`파티원5퍼센트`.
- `/미완료`: 내가 등록해야 하는 건과 내가 구매해야 하는 건을 각각 오래된 순 10행까지 본인에게만 보여준다. 11행을 조회해 더 있으면 “더 있어요”를 표시한다. UUID는 표시하지 않는다. 올릴 건에는 분배자, 경매장 등록가, 채널, 생성일을, 구매할 건에는 파티원, 아이템 이름(등록 전은 대기), 금액, 상태, 채널, 생성일을 표시한다. 안내와 조회는 임베드 카드로 보여 준다.
- `/미완료`와 `/내역` 날짜는 Discord 타임스탬프(`<t:유닉스초:d>`)로 표시해 보는 사람의 현지 날짜로 보여준다.
- `/내역`: 이 서버에서 내가 참여한 분배 중 취소 건을 제외한 최근 10건을 본인에게만 보여준다. 취소 건은 10건 제한을 차지하지 않으며 기록은 지우지 않는다. 페이지 넘김은 없다.
- 등록 전 구매 완료 버튼은 잠기며 서버와 DB에서도 거절한다. 파티원이 경매장 등록 버튼을 눌러 제출해야 구매 완료가 가능하다. 누르지 않으면 분배자는 취소만 할 수 있다. 기존 uploaded 기록은 이름이 NULL이어도 구매 가능하다.
- 구매 알림은 실제 상태 전환 때만 원본 갱신 callback 성공 후 보낸다. 파티원만 멘션 알림 대상이며 분배자·전체 멘션은 비활성화한다. 마지막 구매에도 알리고 완료 리액션을 시도한다. 토큰이 없으면 type 7 갱신만 하며, callback·알림 실패는 상태를 되돌리거나 재시도하지 않고 action(알 수 있을 때)과 status만 기록한다.
- 모든 조회는 현재 서버로 한정하며 멘션 알림을 보내지 않는다.

### 비율 표시
- 안내 카드에서 분배자와 0% 제외 파티원의 정확한 비율이 모두 같으면 퍼센트를 숨긴다. 하나라도 다르면 전원에게 표시하며 0% 분배자도 포함한다.
- 미지정 비율은 분배자와 제외 파티원을 포함한 모든 지정 비율의 합을 100%에서 빼고 미지정 인원이 균등 분배한다. 같은지 비교는 반올림 전에 수행한다.
- 소수점 둘째 자리까지 반올림하고 뒤의 0을 뺀다. 반올림 때문에 표시 합계는 100%가 아닐 수 있다. 금액 계산은 바꾸지 않는다.

### 금액 표시
- 금액은 끝에서 네 자리씩 끊어 억·만 단위를 붙이고, 0인 자리도 생략하지 않으며 공백 없이 모든 자릿수를 표시한 뒤 ` 메소`를 붙인다. 예: `2억0005만0000 메소`.
- 경매장 등록가는 단위 표기만 굵게 하고, 뒤에 쉼표·공백·서식 없는 원래 숫자를 괄호로 덧붙인다. 예: `**2억4619만2893 메소** (246192893)`.

## 3. 입력 검증과 기록 보관
- 분배 퍼센트는 `50`과 `50%` 모두 허용한다. 끝의 `%`는 하나만 가능하며 0~100, 소수점 둘째 자리까지 입력한다. 공백·지수 표기·셋째 소수자리는 거부한다.
- 입력 검증 — 파티원 중복, 봇 계정, 분배자 본인을 파티원으로 넣는 경우, 총판매액이 0 이하이거나 안전한 정수가 아닌 경우는 거부한다. 모든 파티원의 몫이 0%인 분배도 거부한다.
- 아이템 이름은 앞뒤 공백과 줄바꿈을 정리해 원문으로 저장하고, 출력 시 마크다운·멘션·링크 문법을 이스케이프한다. 입력창을 연 뒤에도 제출 시 권한과 현재 상태를 다시 확인한다. 구매 완료·분배 종료 후에는 저장하지 않고 원본 메시지의 최신 상태를 보여 준다. 기존 등록 기록의 이름이 비어 있으면 `아이템 미입력`으로 표시한다.
- 분배 기록은 완료 후에도 보관한다. 취소한 분배도 지우지 않고 취소 상태로 남긴다.
- 분배 퍼센트가 0%인 파티원은 금액 안내와 버튼 대상에서 빼고 전원 구매 완료 판단에서도 제외한다. 분배 기록에는 몫 0으로 남긴다.

## 4. 1차에서 제외
- 아이템별 드랍 기록: 분배자가 합계만 입력하므로 필요 없다. 파티원이 분배금을 받으려고 경매장에 올린 아이템 이름 기록과는 다르다.
- 고정 파티 저장: 편의 기능이라 실제 사용해 보고 필요하면 추가한다.
- 넥슨 Open API 연동: 분배 계산에 필요 없다.
