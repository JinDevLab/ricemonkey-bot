# 기능 명세
분배 규칙과 용어는 [도메인 문서](domain.md)를 따른다.

## 1. 봇의 역할
봇은 기존 분배 방식의 계산과 멘션, 진행 확인을 대신한다. 게임 안의 거래는 볼 수 없으므로 상태는 사람이 누른 표시만을 기준으로 한다.

## 2. 1차 범위

| 단계 | 하는 사람 | 봇의 동작 |
|---|---|---|
| 분배 만들기 | 분배자 | 총 판매금액, 판매 수수료, 파티원, 분배 퍼센트(선택)를 입력받아 올릴 금액을 계산한다. |
| 금액 안내 | 봇 | 파티원을 멘션하고 각자 올릴 금액과 예상 실수령액을 보여준다. |
| 올렸어요 표시 | 해당 파티원 본인만 | 해당 파티원 상태를 바꾸고 분배자에게 알린다. |
| 구매 완료 표시 | 분배자만 | 해당 파티원을 완료로 바꾼다. 파티원이 말로만 알린 경우를 위해 올렸어요 표시 없이도 누를 수 있다. |
| 분배 완료 | 봇 | 전원이 구매 완료면 메시지를 완료 상태로 바꾸고 이모지를 남긴다. |
| 분배 취소 | 분배자만 | 잘못 입력하면 취소하고 다시 만든다. 이미 구매한 건은 봇이 되돌리지 못한다. |
| 미완료 조회 | 누구나 | 내가 올려야 하는 건과 내가 구매해야 하는 건을 보여준다. |
| 내역 조회 | 누구나 | 내가 분배자나 파티원으로 참여한 분배를 최근 순으로 보여준다. 날짜, 분배자, 총 판매금액, 내 몫, 상태를 표시하고 조회한 본인에게만 보인다. |

## 3. 입력 검증과 기록 보관
- 입력 검증 — 파티원 중복, 봇 계정, 분배자 본인을 파티원으로 넣는 경우, 총 판매금액이 0 이하인 경우는 거부한다.
- 분배 기록은 완료 후에도 보관한다. 취소한 분배도 지우지 않고 취소 상태로 남긴다.

## 4. 1차에서 제외
- 아이템별 드랍 기록: 분배자가 합계만 입력하므로 필요 없다.
- 고정 파티 저장: 편의 기능이라 실제 사용해 보고 필요하면 추가한다.
- 넥슨 Open API 연동: 분배 계산에 필요 없다.
