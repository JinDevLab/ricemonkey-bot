# 개인정보 처리 안내

시행일: 2026-11-01

## 저장 항목과 목적
ricemonkey-bot은 분배 계산, 참여자 확인, 카드 게시, 등록·구매 진행 관리와 본인 내역 조회를 위해 다음 정보를 저장한다.

- Discord 서버 ID, 채널 ID, 분배자와 파티원의 사용자 ID
- 파티원 표시 이름
- 총판매액, 판매 실수령액, 경매장 등록가, 예상 실수령액, 분배자 최종 금액
- 판매 수수료와 분배 비율
- 파티원이 입력한 경매장 아이템명
- 분배 및 파티원의 진행 상태
- 생성·등록·구매·완료·취소 시각

분배를 구분하는 내부 ID와 파티원 표시 순서, 비공개 스레드 분배 여부도 함께 저장한다. 비공개 분배의 채널 ID는 스레드 ID다. 게임 계정이나 실제 게임 거래 내역은 조회하지 않는다.

## 확인 전 임시 기록
입력창 제출 뒤 금액 확인과 다시 입력을 위해 `split_drafts`에 임시 ID, 서버 ID, 작성자 사용자 ID, 생성 시각과 `StoredSplit` JSON을 저장한다. JSON에는 원래 채널 ID, 공개/비공개 여부, 분배자·파티원 ID와 파티원 표시 이름·순서, 총판매액·수수료·계산된 금액, 기본 비율과 초기 상태·시각이 포함된다. 아직 입력하지 않은 아이템명·등록·구매 시각은 비어 있다. 토큰은 저장하지 않는다.

미리보기는 공개·비공개 모두 작성자에게만 보이고 멘션 알림을 보내지 않는다. 확인하면 임시 기록을 원자적으로 지우고 분배를 만들며, 다시 입력은 같은 기록을 교체한다. 확인하지 않은 기록은 최초 생성 후 24시간이 지나면 매일 KST 03:00 정리 작업에서 삭제한다. 정확한 경계는 남겨 다음 실행에서 삭제하므로 일일 정리 시점에 따라 최대 약 48시간 남을 수 있고, 정리가 실패하면 더 길어질 수 있다. 별도의 24시간 만료 검사는 없으므로 기록이 남아 있는 동안에는 미리보기에서 확인하여 분배를 만들 수 있다. 수정으로 보관 기한을 늘리지 않는다. 이 변경은 아직 배포하지 않았다.

## 처리 위치와 전달
상호작용은 Cloudflare Workers에서 처리하고 분배 정보는 Cloudflare D1에 저장한다. 입력창, 카드와 알림은 Discord에서 처리·표시된다. 이 서비스 제공에 필요한 처리를 제외한 별도 제3자 제공이나 광고 목적 이용은 하지 않는다.

## 비공개 스레드와 열람 범위
`/분배`로 만든 카드와 알림은 채널에 공개된다. `/분배패널`의 버튼으로 만들면 입력 검증과 나만 보기 금액 확인 후 분배자와 선택한 파티원을 비공개 스레드에 추가하고 그 안에 카드·금액·아이템명·알림을 게시한다. 스레드 관리 권한자는 초대 없이 볼 수 있으므로 참여자만의 완전한 비밀 공간을 보장하지 않는다. 스레드 이름은 분배자 표시 이름을 포함하지만 금액·아이템명은 넣지 않는다.

실패해도 공개 채널 게시로 대체하지 않는다. 초대 실패 등으로 빈 스레드가 남을 수 있고 봇이 자동 삭제하지 않는다. 카드 게시가 4xx(429 포함)로 거절되면 저장 행 삭제를 시도하고, 정리도 실패하면 본인에게 `/미완료` 복구를 안내한다. 5xx·네트워크 오류로 게시 결과가 불명확하면 이미 게시된 카드의 버튼이 동작하도록 행을 유지하고, 스레드 확인 후 카드가 없으면 `/미완료`로 다시 올리도록 안내한다. 저장 예외도 커밋 여부가 불명확하므로 삭제를 시도하며, 삭제까지 실패하면 `/미완료`에 보이는 경우 원래 스레드에 다시 올리도록 안내한다. 재게시에는 멘션 알림을 보내지 않는다. 0% 제외 파티원은 제외 안내를 볼 수 있도록 스레드에서 내보내지 않는다. 완료·취소 후에도 잠그거나 보관하지 않으며 7일 무활동 자동 보관은 기록 삭제가 아니다. `/미완료`·`/내역`은 기존과 같이 조회자 본인에게만 표시한다.

## 운영 로그
`wrangler.jsonc`의 observability가 켜져 있어 Cloudflare Workers Logs에 호출 로그와 봇의 `console` 출력이 남는다. [Cloudflare 공식 안내](https://developers.cloudflare.com/workers/observability/logs/workers-logs/)에 따르면 보관 기간은 Free 3일, Paid 7일이다(2026-10-31 확인). 호출 로그에는 요청·응답과 관련 메타데이터가 포함된다. 요청 헤더의 포함 여부나 세부 수집 범위는 이 안내에서 확인하지 못했으므로 단정하지 않는다.

봇이 직접 남기는 값은 오류·작업 라벨, 알림·리액션의 동작 이름과 HTTP 상태 코드(네트워크 오류는 null), 처리 오류의 이름·메시지, 자동 삭제한 분배·파티원·임시 기록 건수다. 처리 오류의 이름·메시지는 알려진 토큰과 URL을 마스킹한다. 자동 삭제 SQL의 바인딩은 기준 시각뿐이며 실패 시 오류 이름·메시지를 기록하고 실패를 전파한다. 카드 본문, 금액, 아이템명, 사용자 ID나 토큰 자체를 로그 항목으로 남기지 않는다.

## 보관과 삭제
분배는 생성 후 달력 기준 3개월이 지나면 상태와 관계없이 매일 KST 03:00에 자동 삭제한다. 기준 시각과 정확히 같은 기록은 남기며, 다음 실행에서 삭제된다. 분배와 그 파티원 기록을 함께 삭제하므로 진행 중인 분배도 대상이다.
삭제 기준은 UTC 달력으로 계산하고, 대상 월에 같은 날짜가 없으면 그달 마지막 날로 맞춘다.

삭제 뒤에도 Cloudflare D1 복구 기록(Time Travel)에 요금제에 따라 최대 30일(무료 플랜 7일) 남을 수 있다. [Cloudflare 공식 안내](https://developers.cloudflare.com/d1/reference/time-travel/)를 참고한다.

Discord에 이미 게시된 카드 메시지는 봇이 지우지 않아 DB가 3개월 뒤 삭제돼도 스레드의 카드는 남을 수 있다. 공개 카드는 서버 관리자나 메시지 관리 권한자가 직접 지워야 한다. 비공개 스레드 카드는 메시지 관리 권한만으로는 볼 수 없으므로 스레드 관리 권한자나 메시지 관리 권한이 있는 스레드 멤버가 지워야 한다. 삭제된 분배의 옛 버튼은 분배를 찾을 수 없다는 안내를 반환한다.

## 삭제 요청과 문의
[GitHub Issues](https://github.com/JinDevLab/ricemonkey-bot/issues)로 요청한다. 이슈는 공개되므로 Discord 사용자 ID와 서버 ID 외 다른 정보(이름, 연락처, 금액, 아이템명, 토큰 등)는 적지 않는다.

운영자가 이슈에서 확인 방법을 안내하여 해당 Discord 계정 본인 또는 해당 서버 관리자임을 확인한 뒤 처리한다. 확인하지 못하면 삭제하지 않는다. 해당 서버에서 삭제 대상 사용자가 분배자 또는 파티원으로 참여한 분배와 확인 전 임시 기록(`split_drafts`) 전체를 삭제한다. 같은 분배·임시 기록의 다른 참여자 정보도 함께 삭제된다. Discord 카드 메시지 삭제는 별도로 처리해야 한다. 비공개 스레드 카드는 메시지 관리 권한만으로는 볼 수 없으며 스레드 관리 권한자나 메시지 관리 권한이 있는 스레드 멤버가 지워야 한다. DB가 3개월 뒤 삭제돼도 스레드의 카드는 남을 수 있다.
